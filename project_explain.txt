Название проекта	Система контроля выезда автомобиля за пределы гоночной трассы
Ментор проекта (ФИО, должность, электронная почта, телеграм, телефон)	Артюгин О.Ю. Исполнительный директор SberAI
Цель проекта	Разработка системы, автоматически фиксирующей факты выезда автомобиля за пределы гоночной трассы (пересечения контрольных линий, выход за пределы разметки) на основе видеопотоков с камер, установленных на автодроме, как основного источника данных; телеметрия от системы AiM и при необходимости бортовое видео используются как дополнительная информация для уточнения и валидации; результат служит материалом для отсмотра судьями при разборе инцидентов
Результат (продукт) (содержит ожидаемый результат проектной деятельности)	Программный модуль, получающий на вход в первую очередь видеопотоки с камер автодрома; при необходимости — телеметрию с автомобиля (система AiM), видеопоток с бортовой камеры и данные GPS; выдающий события нарушения границ трассы (факт и тип выезда, время, участок трассы) и привязку к фрагментам видео с камер трассы для отсмотра судьями, анализа пилотажа
Требования к применяемым инструментам и технологиям 	Python, Django (предпочтительно) или FastAPI, PostgreSQL. Альтернативный стек
Требования к компетенциям участников проекта (перечень необходимых компетенций, без которыми студенты не допускаются к участию в проекте)	Python. Инструменты: библиотеки для компьютерного зрения для детекции объектов/сегментации; средства работы с видео (декодирование, синхронизация потоков, извлечение кадров)
Описание проекта (до 2 страниц)	В современном автоспорте контроль соблюдения границ трассы (track limits) критичен для честного судейства, безопасности и анализа техники пилотирования, однако стандартные средства (GPS, ручной просмотр видео) либо недостаточно точны, либо требуют значительных трудозатрат. Проект направлен на разработку системы, в которой **основным источником данных служат камеры, установленные на автодроме**: по их видеопотокам система автоматически выявляет факты пересечения контрольных линий и выезда автомобиля за пределы разметки. Телеметрия от системы AiM (скорость, ускорения, рулевое управление и др.), а при необходимости бортовое видео и GPS используются как дополнительная информация для уточнения сомнительных случаев и валидации. Результат — структурированные события нарушений с привязкой к фрагментам съёмки с камер трассы, которые судьи могут непосредственно отсматривать при разборе инцидентов.  Проект носит научно-прикладной характер: с одной стороны, решаются задачи компьютерного зрения по видеопотокам с камер автодрома и при необходимости слияния с телеметрией для устойчивого распознавания выездов за линию в реальных условиях; с другой — результат даёт судьям верифицируемый видеоматериал с трассы для принятия решений и может использоваться в школах пилотажа и инженерных командах для объективной обратной связи пилоту.
Критерии приемки результата проекта (описание функциональных требований и конструктивных особенностей ожидаемого результата)	Работоспособный код с реализованными функциональнми требованиями в соответствии с техническим заданием, техническая документация.
Ожидаемый образовательный результат проекта (чему студенты могут научиться на проекте)	Компетенции командной разработки, управление проектами, работа с CV моделями, обучение моделей, сбор датасетов
